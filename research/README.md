# Research archive

Dated investigations, task briefs, reports and selected evidence are retained to explain the recovered device contracts and rendering work. Start with [current status](../docs/status.md) and [architecture](../docs/architecture.md) for the maintained overview.

These are historical records, not a fresh-clone tutorial. Some referenced `backend/evidence/`, scratchpad files, shared caches and firmware are intentionally absent. References to removed agent handovers describe historical inputs; maintained conclusions now live in `docs/`. `${REPO_ROOT}`, `${WORKTREES_ROOT}`, `${GRAPHICS_RESEARCH_ROOT}` and `${LOCAL_ARTIFACTS}` replace original machine paths. Commands using these placeholders require your own local artifacts.

Useful entry points:

- [Native bootstrap](bootstrap-launchd-20261013.md) and [storage audit](continuation-20261013-storage.md)
- [SMP](T16-smp.md)
- [Home acceptance](reports/H-home-live.md)
- [Virtual activation](reports/virtual-activation-20261023.md)
- [Graphics and input reports](reports/)

Screenshots document particular historical runs. Some crops are simulated/offline diagnostics; their filenames and reports identify them. They must not be presented as new live acceptance evidence.
