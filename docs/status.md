## Latest integration notes retained from internal handovers

Clock/slider fixes were merged at `5df6884`; blur/switch work and follow-up `f5779b1` are included in the baseline. Local integration records reported lock, Home and Settings with no panic, thin clock hands, removal of slider artifacts, and elimination of the switch's grey shadow square. The final switch follow-up adds 9-slice texture sampling and the navigation-bar color matrix. Selected Home/Settings captures from that run are now preserved with [provenance](../research/evidence/public-readme-20261024/README.md); the full live logs are not committed. This is historical evidence, not a newly verified release acceptance run.

Open issues include a faint remaining UISwitch shadow corner, incomplete verification of the glint sweep, 52 canvas-backdrop blurs whose taps are not yet read from shader constants, and TCG timing that can skip visible Home animation. On 2026-10-24 the scripted unlock in `merge-live.sh` failed on main `539270b` as well as on `gfx/fidelity-2` while Spotlight indexing loaded the host. A later `merge-live.sh` run of `gfx/fidelity-2` at `76274c1` reached lock, unlock, Home (antialiased Clock icon hands) and Settings with no panic; Settings was still launching at the 152 s capture and fully drawn by the end of the run. That run also caught a regression from the GD sampling change: stride-36 lock-screen grabber/camera draws rendered as solid black bars. It was fixed by restoring the earlier handling, which leaves the small dark marks also seen on main. Time dilation was evaluated on an independent experimental branch and was not merged. At k=2/k=3 the lock screen appeared sooner, but unlock did not complete despite slider movement. The decision recorded in main is to keep the default k=1; the proposed inter-daemon timing explanation remains unproven. Wi-Fi single synthetic AP join and DHCP were recorded in a dedicated native research boot ([Report W](../research/reports/W-wifi-native.md)), but host-mirrored scan is NOT yet accepted until a native run is recorded. Do not infer networking, native SEP execution, full GPU support, or general application compatibility from a rendered Home screen.

Performance work on branch `perf/integrate` ([report](../research/reports/P-performance.md)): GUI launches no longer enable `-d int,unimp` and use MTTCG; AGX doorbell-to-completion latency dropped from about 5 ms to about 0.3 ms (p50), live AGX passes rose about 25%, the offline renderer is 1.73x faster with bit-exact output, and the native player presents through an IOSurface. Boot remains TCG-bound.

The CPU is a Cortex-A57 prototype under TCG with selected Apple register behavior, not Cyclone. Storage uses a modeled ASP interface. iOS 8/9 are not supported. Native shutdown, Notes persistence through a clean shutdown, a complete Settings/Calculator/Notes input acceptance run, and a 15-minute stability session remain release criteria.

Stability work on branch `perf/stab-integ`: QEMU vCPU and main-loop threads request `USER_INTERACTIVE` QoS on macOS and the vblank timer keeps its phase across WFI (pacing histogram under `VPHONE_PERF_STATS`); ANS storage defers `fsync` (300 ms write-back, synchronous on guest flush, reset and exit) and batches contiguous sectors, so a host crash can lose up to that window of buffered writes; the player no longer copies a full frame per update and presents through a four-surface ring that never writes a displayed surface; back-to-back mouse presses queue behind a draining contact instead of being dropped. Renderer fixes: dedicated NC scratch buffer and zeroed pooled pages, antialiased clock-hand strokes, UISwitch track mask rows, sparse 640x640 offscreen targets (Extras folder panel and blur persist after the zoom-in), and the folder icon mask UV transform. These were validated by offline corpus replay and tests only; the pacing, storage and folder changes have not been re-measured against a live baseline. The Home-button delay, the faint rounded corner at the bottom of the folder panel, and keyboard glitches under Safari are not resolved.
